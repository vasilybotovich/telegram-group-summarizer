# Telegram Group Summarizer

Автономный Telegram-бот: после одобрения владельцем собирает текст и медиа групп и публикует краткие AI-саммари со ссылками на источники отдельно в каждой активной теме.

## Поведение

- единственный управляющий — `ADMIN_USER_ID`;
- сбор начинается только после явного одобрения группы;
- одна периодичность на группу: ежедневно, по пятницам или в последний день месяца — всегда в 20:00 мск;
- темы без сообщений пропускаются;
- после успешной публикации обработанные тексты удаляются;
- при ошибке AI владелец получает личное уведомление;
- команды управления можно выполнять прямо в нужной группе без аргументов; в личном чате они принимают `CHAT_ID`: `/settings`, `/pause`, `/resume`, `/summary_now`, `/disconnect`;
- `/summary_now` немедленно анализирует сообщения текущей группы за выбранное в настройках окно: последние 24 часа, 7 или 30 дней.
- сводки публикуются в аккуратном HTML-формате; ссылки добавляются кодом только к реально доступным исходным сообщениям, без выдуманных URL и дат-ссылок;
- `/import_history` внутри нужной темы создаёт безопасную сессию импорта: администратор пересылает старые сообщения боту в личный чат и завершает импорт кнопкой; сообщения привязываются к исходной группе и выбранной теме, фильтруются по настроенному периоду и дедуплицируются.
- фотографии и скриншоты распознаются моделью `qwen3.5-flash`;
- голосовые сообщения и аудиофайлы длительностью до 5 минут расшифровываются моделью `qwen3-asr-flash`;
- импорт принимает текст, изображения и аудио; первое принятое сообщение подтверждается;

Telegram не разрешает боту первым писать человеку: владелец должен заранее нажать `/start` в личном чате. Для чтения всех сообщений в @BotFather нужно отключить Privacy Mode (`/setprivacy` → Disable).
Telegram не предоставляет боту историю до его добавления: в принудительную сводку попадают только сообщения, полученные после подключения и активации группы.

## Конфигурация

Скопируйте `.env.example` в `.env` локально либо задайте переменные окружения на хостинге. Обязательны `BOT_TOKEN` и `DASHSCOPE_API_KEY`. Секреты не должны попадать в Git.

## Запуск и тесты

```bash
python -m venv .venv
. .venv/bin/activate
pip install -r requirements.txt pytest pytest-asyncio
pytest -q
python main.py
```

В Bothost используется постоянная база `/app/data/bot.db`, Python 3.11 и `Dockerfile`.

## Безопасность и приватность

Медиа скачиваются только в оперативную память и после распознавания освобождаются. В базе временно хранится только текст, описание изображения или расшифровка аудио, необходимые для следующей сводки. Данные передаются Alibaba Cloud DashScope, затем удаляются после публикации. Токены задаются только через защищённые переменные окружения.
