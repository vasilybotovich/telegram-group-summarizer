# Telegram Group Summarizer

Автономный Telegram-бот: после одобрения владельцем собирает текстовые сообщения групп и публикует краткие AI-саммари со ссылками на источники отдельно в каждой активной теме.

## Поведение

- единственный управляющий — `ADMIN_USER_ID`;
- сбор начинается только после явного одобрения группы;
- одна периодичность на группу: ежедневно, по пятницам или в последний день месяца — всегда в 20:00 мск;
- темы без сообщений пропускаются;
- после успешной публикации обработанные тексты удаляются;
- при ошибке AI владелец получает личное уведомление;
- команды управления принимают `CHAT_ID`: `/settings`, `/pause`, `/resume`, `/summary_now`, `/disconnect`.

Telegram не разрешает боту первым писать человеку: владелец должен заранее нажать `/start` в личном чате. Для чтения всех сообщений в @BotFather нужно отключить Privacy Mode (`/setprivacy` → Disable).

## Конфигурация

Скопируйте `.env.example` в `.env` локально либо задайте переменные окружения на хостинге. Обязательны `BOT_TOKEN` и `DASHSCOPE_API_KEY`. Секреты не должны попадать в Git.

## Запуск и тесты

```bash
python -m venv .venv
. .venv/bin/activate
pip install -r requirements.txt pytest pytest-asyncio
pytest -q
python main.py
```

В Bothost используется постоянная база `/app/data/bot.db`, Python 3.11 и `Dockerfile`.

## Безопасность и приватность

В базе временно хранится только текст сообщений, необходимый для следующей сводки. Тексты передаются Alibaba Cloud DashScope модели `qwen3.5-flash`, затем удаляются после публикации. Токены задаются только через защищённые переменные окружения.
