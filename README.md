# Telegram Group Summarizer

Автономный Telegram-бот: после одобрения владельцем собирает текст групп и публикует краткие AI-саммари со ссылками на источники отдельно в каждой активной теме.

## Поведение

- единственный управляющий — ADMIN_USER_ID;
- сбор начинается только после явного одобрения группы;
- бот сохраняет только текст сообщений и текстовые подписи к вложениям;
- изображения, голосовые, аудио, видео, документы и другие вложения не скачиваются, не анализируются и не передаются AI-сервису;
- вложения без текста молча пропускаются и не создают уведомлений об ошибках;
- одна периодичность на группу: ежедневно, по пятницам или в последний день месяца — всегда в 20:00 мск;
- темы без сообщений пропускаются;
- после успешной публикации обработанные тексты удаляются;
- временные ошибки создания сводки повторяются до трёх раз, после чего владелец получает понятное личное уведомление;
- сбой одной темы не останавливает остальные: её сообщения сохраняются до следующей попытки;
- повторяющиеся одинаковые уведомления подавляются на один час;
- команды управления можно выполнять прямо в нужной группе без аргументов; в личном чате они принимают CHAT_ID: /settings, /pause, /resume, /summary_now, /disconnect;
- /summary_now анализирует текст текущей группы за выбранное окно: последние 24 часа, 7 или 30 дней;
- /import_history создаёт сессию импорта старых сообщений. Импортируются только текст и текстовые подписи, а сами вложения игнорируются;
- сводки публикуются в HTML-формате; ссылки добавляются только к реально доступным исходным сообщениям.

Telegram не разрешает боту первым писать человеку: владелец должен заранее нажать /start в личном чате. Для чтения всех сообщений в @BotFather нужно отключить Privacy Mode (/setprivacy → Disable).
Telegram не предоставляет боту историю до его добавления: в принудительную сводку попадают только сообщения, полученные после подключения и активации группы.

## Конфигурация

Скопируйте .env.example в .env локально либо задайте переменные окружения на хостинге. Обязательны BOT_TOKEN и DASHSCOPE_API_KEY. Модель итоговой сводки задаётся через QWEN_MODEL. Темы, в которых бот не должен публиковать сводки, задаются через EXCLUDED_THREAD_IDS списком идентификаторов через запятую. Секреты не должны попадать в Git.

## Запуск и тесты

    python3 -m venv .venv
    . .venv/bin/activate
    pip install -r requirements.txt pytest pytest-asyncio
    pytest -q
    python3 main.py

В BotHost используется постоянная база /app/data/bot.db, Python 3.11 и Dockerfile.

## Безопасность и приватность

В базе временно хранится только текст, необходимый для следующей сводки. Вложения не загружаются и не передаются внешним сервисам. Текст передаётся Alibaba Cloud DashScope только для создания сводки и удаляется из базы после успешной публикации. Токены задаются только через защищённые переменные окружения.
